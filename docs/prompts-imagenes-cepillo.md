# Prompts de imágenes · Cepillo Eléctrico de Limpieza

Para Gemini (Nano Banana), ChatGPT o Flux Kontext.

**Cómo usarlo**
1. Abre un chat nuevo y pega primero el **MENSAJE MAESTRO** junto con 2–4 fotos reales del producto: de frente, de lado, con el mango extendido y con todos los cabezales.
2. Después pega los prompts **uno por uno**, en orden. Si un prompt dice «+ referencia», adjunta también tu imagen de referencia en ese mensaje.
3. Si el producto cambia (otro color, otra forma, más o menos cabezales), responde: *"The product changed. Keep it EXACTLY like the product photos I sent: same shape, colors, buttons and brush heads. Regenerate."*
4. Revisa siempre las manos, los dedos y que no aparezca texto raro.

> **No generes con IA:** reseñas, fotos de clientes ni antes/después. Esas secciones son solo para fotos reales.

---

## MENSAJE MAESTRO (pegar primero, con las fotos del producto)

```
You are a professional product and lifestyle photographer for an e-commerce brand in Chile.
The attached photos show my REAL product: a cordless electric spin scrubber with a telescopic
handle and interchangeable round brush heads, plus a USB charging cable.

Rules for EVERY image I ask for in this chat:
1. The product must look EXACTLY like the attached photos: same shape, proportions, colors,
   materials, buttons, handle and brush heads. Never redesign it, never add parts it doesn't have.
2. Photorealistic, natural light, clean and bright, modern Chilean home (apartment or house),
   white/light grey tiles, light wood, plants, tidy but lived-in.
3. People: real-looking Latin American adults (30–45), casual home clothes in neutral colors
   (white, beige, light blue), natural skin, no heavy makeup, relaxed and satisfied expression.
   Keep the SAME main woman across images unless I say otherwise.
4. Brand color mood: navy blue and aqua/turquoise accents (towels, details), never green.
5. No text, no logos, no watermarks, no brand names on the product, unless I ask for text.
6. Correct hands: five fingers, natural grip on the handle.
Confirm you understood and wait for my first request.
```

## Dónde va cada imagen en Shopify

| Imágenes | Dónde se suben |
|---|---|
| G1–G8 | **Productos → Cepillo → Multimedia**, en ese orden. Si tienes un video demostrativo, súbelo primero. |
| A1 | Editor → sección **Anatomía** → Imagen |
| I1–I4 | Sección **Esto incluye tu compra** → cada pieza → Foto. También bloque «Tu compra incluye» → Foto 1–4 |
| T1–T4 | Sección **Pestañas de uso** → cada pestaña → Imagen |
| P1 | Sección **De fregar a mano…** → Imagen |
| C1 | Sección **CTA final** → Imagen |
| K1–K2 | Bloque **Packs** → Imagen del Pack 1 y Pack 2 |
| H1–H5 | Sección **Un cabezal para cada trabajo** (actívala) → cada cabezal → Foto |
